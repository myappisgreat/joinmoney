# 合成錢克禮

使用「照片」資料夾內的 14 張照片製作的合成遊戲。照片依原檔案日期排序，轉成裁切後的 WebP 小圖；原始照片保留於專案外的原資料夾。

## 開始遊戲

直接用瀏覽器開啟 `index.html` 即可遊玩，不需要安裝套件或連接外部 CDN。

也可以安裝 Node.js 後執行 `npm start`，開啟 `http://127.0.0.1:4173`。

## 操作與規則

- 電腦：移動滑鼠瞄準，點擊投放；鍵盤左右鍵瞄準、空白鍵投放，P 暫停、R 重開。
- 手機：在棋盤上拖動瞄準，放開投放。
- 兩張相同階級的照片碰撞後變成下一階，共有 14 階。
- 照片穩定堆過警戒線約 2 秒後結束遊戲。
- 每 2,000 分可獲得一枚復活幣，復活時清除頂部照片。
- 兩個第 14 階互撞會一起消除，加 500 分並獲得一枚復活幣。
- 目前進度、最佳分數、已解鎖圖鑑和前 10 場分數紀錄，儲存在目前瀏覽器的 localStorage。不同裝置與瀏覽器不共用紀錄。

## 檔案

- `index.html`：網頁結構，也是 GitHub Pages 網站入口。
- `styles.css`：電腦與手機版樣式。
- `game.js`：遊戲、物理引擎整合與本機存檔。
- `assets/photo-01.webp` 至 `photo-14.webp`：14 階照片，可更換同名圖片。
- `vendor/matter.min.js`：Matter.js 0.20.0，MIT 授權，授權全文見同資料夾內的 `MATTER-LICENSE.txt`。
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔案。

遊戲入口已放在儲存庫根目錄，可供 GitHub Pages 使用；開啟 GitHub Pages 服務後，將來源指定為這個分支的根目錄即可。

`npm test` 驗證碰撞升級、異階碰撞、連鎖合成、最終階消除和復活清場。

玩法參考：[合成大奶娃](https://yhsome.github.io/BigNaiWa/v1/)。本專案的介面與程式另行實作。
